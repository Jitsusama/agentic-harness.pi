# Browser Accessibility Guide

Teaches the LLM how to audit a page for accessibility with the
browser tools, and how to report what it finds without
overstating it.

Covers the order to work in (keyboard first, then the rule sets,
then reading order and announcements, then contrast and target
size, then the conditions that break them), the distinctions the
reports draw between WCAG criteria and best practice and between
failures and undecided results, and the list of things the tools
deliberately refuse to judge.

Paired with the `browser-integration` extension. See
`browser-guide` for the tool surface.
