# Browser Guide

Teaches the LLM how to drive the four browser tools:
`browser_go` for where a session is and the conditions it runs
under, `browser_see` for reading, `browser_do` for changing the
page, `browser_check` for forming a verdict.

Covers the split between the verbs, addressing elements by role
and accessible name rather than by selector, the observe-act
loop, keeping answers inside a context budget, and how to read a
verdict without turning "could not decide" into "fine".

Paired with the `browser-integration` extension. See
`browser-accessibility-guide` for auditing method.
