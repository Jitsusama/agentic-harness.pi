# result-query-guide

How to read a tool answer that cites a stored handle, and how to
query it.

Teaches the shared JSONPath language behind `result_query`: when to
query rather than re-run a tool, why to project fields instead of
returning whole records, how to count matches without fetching
them, and what each tool family's stored payload looks like.

Pairs with the `result-store-workflow` extension, which owns the
store and registers the tool.
