# Mesh Workflow Tests

The mesh-workflow extension driven through its tools and events, each
file one behaviour a session sees: sending, answers, holds, needs,
leases, steering, carrying and what the person is told. `support/`
holds the fake peers and transport they share.

Many entries because each file is one behaviour of the extension with
its own fixtures, and grouping them into folders would only part files
that share `support/`.
