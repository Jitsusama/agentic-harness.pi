# Quest Verbs

The quest tool's verbs, through the tool as a session calls it, named
after the verb or the `extensions/quest-workflow/verbs/` module they
test: creating, listing, ordering and reparenting quests, attaching
aliases and sessions, documents, trees, orchestration, spawning,
budgets, needs, weights, realms and undo, and the tool's declaration,
renamed actions and dry runs.
