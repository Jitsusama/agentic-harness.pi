# Review Round Tests

The tests of asking models to review a change through `review_ask`: the
roster and what each reviewer runs with, a round's panel, job and
record, where a round runs, and collecting a round nobody lived to
finish.

Many entries because each file holds one behaviour of a round, named
for what it holds, and a round's behaviours share one job and one
record: split into folders by roster, running and collecting, a case
that starts a round in one would lean on the fixtures of another, and
the names already say which part each holds.
