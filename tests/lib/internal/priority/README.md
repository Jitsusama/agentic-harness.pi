# Priority Library Tests

The tests of `lib/internal/priority`, a file for each of its modules:
what a heavy command is, whose turn comes next, what the machine can
take, and how a turn is waited for, run and recorded, with the helpers
that build a line of jobs and a queue folder for them.

Many entries because they mirror `lib/internal/priority` file for
file, so a split here would have to split the library first.
