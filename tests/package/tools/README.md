# Rules Every Tool Keeps

How a tool is registered and how it answers: it reads its arguments from
the second parameter, names which actions a parameter serves, says the
glossary's words, bounds an answer that can grow big, and refuses with
what to do instead. A skill names only tools that exist.

`registered-tools.ts` finds every registered tool for the tests here, and
`core-glossary.txt` is the copy of core's glossary they read the words
against.
